# PinkSasha v1

Первая цельная рабочая версия:

- регистрация по имени и паролю;
- вход и сохранение сессии;
- список зарегистрированных пользователей;
- личные чаты;
- отправка сообщений;
- редактирование и удаление своих сообщений;
- адаптивный розовый интерфейс.

## Публикация GitHub Pages

1. Загрузите всё содержимое этого архива в корень репозитория `pinksasha`.
2. GitHub → Settings → Pages.
3. Source: `Deploy from a branch`.
4. Branch: `main`, folder: `/(root)`.
5. Адрес: `https://yalacom.github.io/pinksasha/`

Серверная часть находится в отдельном архиве Supabase.
